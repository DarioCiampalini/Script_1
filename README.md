# Script_1

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)]()

## Descrizione
Script Python per l'elaborazione e l'analisi di dati geologici e geomorfologici. Fornisce strumenti per il processamento di immagini, estrazione di parametri e generazione di report strutturati.

## Requisiti
Installare le dipendenze principali:
```bash
pip install numpy pandas matplotlib scipy opencv-python
```

## Installazione e uso rapido
1. Clonare il repository:
   ```bash
   git clone https://github.com/DarioCiampalini/Script_1.git
   cd Script_1
   ```
2. Installare le dipendenze (vedere sezione Requisiti).
3. Eseguire lo script principale:
   ```bash
   python script.py
   ```

## Output
- Dati elaborati in formato CSV
- Grafici e visualizzazioni in PNG
- Report analitici strutturati
